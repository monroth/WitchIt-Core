# Witch It+ core — source

Source code of the base libraries, as built for nightly 202611210204 (commit e3915ad8).

- `runtime-source/` — the Lua libraries: WitchItRuntime and Core, UI Kit, Map Markers, WorldKit. Each one's tests are in its `tests/`.
- `consumer/` — the native part loaded by our UE4SS build.
